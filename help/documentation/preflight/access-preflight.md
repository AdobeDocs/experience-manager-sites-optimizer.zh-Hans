# 访问 Preflight

Preflight在AEM Sites创作环境中可用，包括通用编辑器、基于文档的创作和AEM Sites页面编辑器。 “印前检查”会在您正在创作的页面上作为面板打开。 在该面板中，您[在该页面上运行审核](./audits.md)，预检[显示它找到的任何机会](./audit-results.md)以在发布之前增强页面。

* **通用编辑器**——Preflight 扩展显示在&#x200B;**侧边栏**&#x200B;中。 选择它以打开“印前检查”面板。
* **基于文档的创作** — 从Sidekick中打开“预检”面板，或者打开预览页面内容上的小书签。
* **AEM Sites页面编辑器** — 使用浏览器中的Preflight小书签打开Preflight面板。

面板打开后，选择&#x200B;**分析页面**&#x200B;以开始审核当前页面。

有关设置说明，请参阅 [Preflight 设置](./setup.md)。

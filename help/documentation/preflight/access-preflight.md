# 访问 Preflight

Preflight 可在 AEM Sites 的创作环境中使用，包括通用编辑器、基于文档的创作和 AEM Sites 页面编辑器。Preflight 会在您创作的页面上打开一个面板，在这个页面上[运行审核](./audits.md)，然后[显示找到的任何机会](./audit-results.md)，以便在发布之前改进此页面。

* **通用编辑器**——Preflight 扩展显示在&#x200B;**侧边栏**&#x200B;中。选择该选项，开始审核当前页面。
* **基于文档的创作**——通过 Sidekick 或小书签在您预览的页面内容上运行预检工具，查看机会列表。
* **AEM Sites 页面编辑器**——使用浏览器中的 Preflight 小书签，开始审核。

有关设置说明，请参阅 [Preflight 设置](./setup.md)。

# 预检辅助功能机会

![预检辅助功能机会](./assets/accessibility/hero.png){align="center"}

Sites Optimizer 中的预检无障碍性机会可帮助您识别并解决网站中的无障碍性问题，确保包括残障人士在内的所有人都能顺利使用网站。该机会侧重于评估网站对辅助功能标准的符合程度，并提供可操作的改进建议。

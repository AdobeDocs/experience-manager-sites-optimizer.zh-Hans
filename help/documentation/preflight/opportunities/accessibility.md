# 辅助功能审核

![印前检查准备仪表板中的辅助功能审核](./assets/accessibility/hero.png){align="center"}

Preflight中的&#x200B;**辅助功能**&#x200B;审核根据Web内容辅助功能准则(WCAG)评估您的页面，以帮助确保每个人（包括残障人士）都可以使用该页面。 运行Preflight审核时，它会根据这些辅助功能标准评估页面，并将其发现的问题分组为可在发布之前查看和解决的机会。 有关辅助功能检查及其涵盖的准则的更多信息，请参阅[辅助功能问题](/help/documentation/opportunities/accessibility-issues.md)。

在就绪性仪表板中，展开&#x200B;**辅助功能**&#x200B;类别以查看审核是否通过以及找到的机会数。 选择审核以打开其详细信息页面并处理机会。 每个机会都描述了可访问性问题、其严重性、相关的WCAG规则和合规性级别以及页面上受影响的元素。 当元素具有可读文本时，Preflight会显示该文本，以便您更轻松地识别元素；否则，会显示元素的CSS选择器。 要了解如何解释结果和解决机会，请参阅[印前检查中的审核结果](../audit-results.md)。

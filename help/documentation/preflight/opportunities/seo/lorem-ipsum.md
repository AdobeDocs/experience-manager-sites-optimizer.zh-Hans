# Lorem ipsum审核

**Lorem ipsum**&#x200B;审核可检测页面内容中留下的占位符文本。 对于读者来说，发布带有占位符文本的页面看起来尚未完成，并且可以由搜索引擎编制索引。 审核会标记任何占位符文本，这样您便可以在发布之前将其替换为实际内容。

当审核发现业务机会时，每个业务机会都会标识占位符文本出现的位置。 要了解如何查看和解决机会，请参阅[Preflight中的审核结果](../../audit-results.md)。

# 规范审计

**Canonical**&#x200B;审核将审核您页面上的canonical链接。 正确的规范链接可告知搜索引擎，哪个URL是页面的权威版本，这有助于避免重复内容问题。 审核会标记缺少或不正确的规范链接。

当审核发现机会时，每个机会都会描述问题和建议的更改。 要了解如何查看和解决机会，请参阅[Preflight中的审核结果](../../audit-results.md)。

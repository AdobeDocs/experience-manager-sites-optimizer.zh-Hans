# H1计数审核

**H1计数**&#x200B;审核将审核您页面上的H1标题数量。 通常，页面应该有一个描述性的H1来汇总其内容。 缺少或多个H1标题可能会削弱页面结构及其搜索引擎优化。

当审核发现机会时，每个机会都会描述问题和建议的更改。 要了解如何查看和解决机会，请参阅[Preflight中的审核结果](../../audit-results.md)。

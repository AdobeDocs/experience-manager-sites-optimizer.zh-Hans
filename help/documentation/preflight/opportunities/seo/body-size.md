# 正文大小审核

**正文大小**&#x200B;审核将审核您页面上的正文内容量。 内容非常少的页面可能对读者不那么有用，并且可能在搜索结果中排名不佳。 审核会标记内容似乎不足的页面。

当审核发现机会时，每个机会都会描述问题和建议的更改。 要了解如何查看和解决机会，请参阅[Preflight中的审核结果](../../audit-results.md)。

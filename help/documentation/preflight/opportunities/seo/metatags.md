# 元标记审核

**元标记**&#x200B;审核将审核页面上的元数据标记，如页面标题和元描述。 格式正确的元数据可帮助搜索引擎了解您的内容并改进页面在搜索结果中的显示方式。 缺失、重复或超出建议长度的审核标记标记。

当审核发现机会时，每个机会都会识别受影响的标记及其当前值，并可能包括人工智能生成的价值改进的建议。 要了解如何查看和解决机会，请参阅[Preflight中的审核结果](../../audit-results.md)。

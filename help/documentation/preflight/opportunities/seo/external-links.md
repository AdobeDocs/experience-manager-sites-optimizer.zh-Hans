# 外部链接审核

**外部链接**&#x200B;审核会审核页面上指向其他网站的链接。 审核会检查您正在编辑的页面中的每个外部链接，并标记已损坏、不安全或无法自动验证的链接。

## 为什么它很重要

断开的外部链接是读取器的死端，是向搜索引擎发出的页面未得到良好维护的信号。 外部链接也是您最不容易控制的链接：其他网站可以随时移动、重命名或删除页面，并且您的链接会静默停止工作。 在发布之前检查这些链接会捕获自首次添加后已过期的链接。

## 审核检查的内容

审核会报告出现以下问题之一的每个外部链接的机会：

* **断开的链接：**&#x200B;无法访问该链接，或它返回错误，如`Status 404`、`Status 410`或`5xx`服务器错误。 在以相同方式报告重定向后出现错误的链接。 如果链接网站完全没有响应（例如由于域不再存在），则也会报告为已断开。
* **不安全的链接：**&#x200B;该链接使用`http://`，网站没有将其重定向到`https://`。 开头为`http://`但被重定向到安全`https://`页面的链接未标记。 更新链接以使用`https://`。
* **未验证的链接：**&#x200B;站点已应答但拒绝自动检查，例如因为它需要登录（`Status 401`或`Status 403`）、限制自动请求(`Status 429`)或阻止机器人，就像某些社交网络那样。 重定向次数过多、无法关注的链接也以这种方式报告。 这些链接很可能在浏览器中起作用，因此Preflight不会报告它们已损坏。 相反，它会要求您打开链接并自行确认，然后以较小的影响报告该链接。

链接既不安全，也可能断开，或者既不安全，又不验证，在这种情况下，会报告两个机会。 成功解析的链接不会被标记，即使它已在过程中被重定向也是如此。

## 如何检查链接

外部链接是指其主机与正在编辑的页面不同的任何链接。 主机是域名加上任何非标准端口，如`:8443`。 子域计为不同的主机，因此`blog.example.com`和`example.com`都是`www.example.com`的外部主机。 链接使用的是`http://`还是`https://`并不重要。 指向同一主机的链接，包括指向您自己网站的`http://`链接，已改为由[内部链接](./internal-links.md)审核涵盖。 已忽略`mailto:`、`tel:`和`javascript:`等链接。

您的浏览器无法读取其他网站上链接的状态，因此Preflight会从Adobe服务器而不是创作会话中检查外部链接。 每个链接都会被选中一次，即使它在页面上出现多次或具有不同锚点（如`#pricing`和`#features`）也是如此。 机会会突出显示链接出现的第一个位置。

AEM的链接检查器已标记为无效的链接将包含在审核中，即使编辑器从页面中删除了可单击的链接也是如此。 然后，会重新检查这些链接，而不是信任这些链接，因此不会报告已开始工作的链接。

## 已知限制

* **每个页面检查的链接数：**&#x200B;最多50个不同的外部链接。 超出此限制的链接不会被选中。
* **时间限制：**&#x200B;每个链接都有10秒的超时时间，并且整个检查都有时间限制，以便Preflight保持响应状态。 在超时内未响应的站点将报告为已中断。 在具有多个慢速网站的页面上，某些链接在给定运行中可能无法被选中。
* **私有地址：**&#x200B;解析为私有或内部网络地址（如Intranet站点）的链接未检查且未报告。
* **服务器端视图：**，因为从Adobe服务器检查链接，所以网站在位置、登录或机器人检测方面的行为可能会返回与您在浏览器中看到的不同的结果。 此类链接通常报告为&#x200B;**未验证的链接**，而不是已断开。

## 如何解决

当审核发现机会时，每个机会均描述问题和建议的更改，并标识所涉及的链接。 使用页面&#x200B;**上的**&#x200B;高亮显示跳转到内容中的链接，并在新选项卡中打开该URL以自行确认问题。 对于断开的链接，请将其更新到页面的新位置或将其删除。 对于未验证的链接，请确认它在您的浏览器中正确打开。 要了解如何查看和解决机会，请参阅[Preflight中的审核结果](../../audit-results.md)。

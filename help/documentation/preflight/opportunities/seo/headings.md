# 标题审核

**Headings**&#x200B;审核将审核页面的标题结构。 清晰、有序的标题层次结构有助于读者和搜索引擎了解内容的组织方式。 审核会标记问题，例如标题跳过级别或显示顺序不正确的问题。

当审核发现机会时，每个机会都会标识受影响的标题并描述建议的更改。 要了解如何查看和解决机会，请参阅[Preflight中的审核结果](../../audit-results.md)。

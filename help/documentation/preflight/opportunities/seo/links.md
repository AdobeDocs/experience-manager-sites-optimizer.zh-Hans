# 链接审核

**链接**&#x200B;审核将审核您页面上的链接。 断开或不安全的链接会损害用户体验，并且可能会降低搜索引擎抓取您网站的效率。 审核会标记需要注意的链接，这样您可以在发布之前修复它们。

当审核发现机会时，每个机会都会标识受影响的链接并描述建议的更改。 要了解如何查看和解决机会，请参阅[Preflight中的审核结果](../../audit-results.md)。

# 可读性审核

**可读性**&#x200B;审核将审核页面内容的阅读难易程度。 清晰、结构良好的内容让读者保持参与，并帮助更广泛的受众了解您的信息。 审核会评估内容并提供切实可行的改进建议。

可读性审核支持多种语言的内容，包括：

* 英语
* 法语
* 西班牙语
* 意大利语
* 德语
* 荷兰语

当审核发现机会时，每个机会都会描述问题和建议的更改。 要了解如何查看和解决机会，请参阅[Preflight中的审核结果](../../audit-results.md)。

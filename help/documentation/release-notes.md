# 发行说明

本页记录了Adobe Experience Manager Sites Optimizer中的最新更新、新增功能和改进。

标记为&#x200B;**（提前访问）**&#x200B;的功能可应请求使用 — 请联系您的帐户团队或客户成功工程师为您的组织启用它们。

## 2026年9月28日至10月4日 {#september-28-october-4-2026}

### 新增功能

- **个人AI代理机会（提前访问）** — 通过徽章和指导说明其好处，过滤可帮助个人AI代理阅读您的网站并与之交互的机会。

### 增强功能

- **内部链接部署中断（提前访问）** — 为无法自动修复的链接提供替换URL并部署已验证的更新。
- **替代文本发布状态** — 查看何时在已发布页面上确认替代文本更改处于活动状态，同时保留清除失败和重新检测状态。
- **Core Web Vitals代码修补程序** — 按包含行号和突出显示的添加和删除项的文件审阅修补程序文件。
- **Core Web Vitals代码部署（提前访问）** — 将符合条件的代码修补程序作为拉取请求提交到配置的代码存储库中。

### 错误修复

- Forms辅助功能机会现在支持创建Jira问题。
- 部署跟进链接现在会打开配置的代码存储库。
- 现在，详细的辅助功能报告会打开并显示其内容，而不是重定向到主页或显示为空白。
- 替代文本部署的计数和日期组现在与显示的修复匹配，不包含空的失败部署组。
- 现在，恢复跳过的站点地图和Core Web Vitals建议会可靠地更新其状态。

## 2026年9月21日至27日

### 增强功能

- **常见问题解答结构化数据部署（提前访问）** — 对于使用AEM多站点管理器管理的页面，选择是将结构化数据更新应用到源页面还是仅应用到本地页面。
- **表单部署** — 可靠部署与所选表单变体关联的修复。
- **本地化的体验** — 权限标签和截断的表内容在支持的语言中更加清晰。

### 错误修复

- 只要存在修补程序，即可下载Core Web Vitals修补程序。
- 现在，CSV导出可保留Excel中的本地化字符。
- 当源数据不完整时，性能量度不再保持停滞加载。

## 2026年9月14 - 20日

### 增强功能

- **粒度权限** — 管理员可以授予成员访问所选机会类型的权限，同时单独管理整个站点的权限。

### 错误修复

- 元数据部署现在可恢复修复本地页面中断继承时显示的警告。

## 2026年9月7 - 13日

### 新增功能

- **Google广告投放排除项** — 审查连接的Google广告帐户的投放风险，并下载自动营销活动和效果最佳营销活动的特定于站点的排除列表。

### 增强功能

- **部署失败指南** — 失败消息现在说明内容更新是否需要连接访问、重新扫描或支持。

### 错误修复

- 现在，可访问性报表值和版面在支持的语言间显示得更加清晰。
- 现在，付费流量渠道和平台总数中包含以前未分类的流量。
- 现在，断开的回链接部署计数与显示的行相匹配，包括回滚和回填的部署状态。
- 不再错误地阻止符合条件的Edge Delivery Services站点进行断开链接部署。

## 2026年8月31日至9月6日

### 增强功能

- **AEM内容连接** — 设置现在可以识别AEM创作的Edge Delivery Services配置，保留其源详细信息，并在保存之前阻止不支持的源URL。
- **试用版载入** — 在添加试用版站点之前，域条目现在将说明受支持的生产站点要求。

### 错误修复

- 现在，付费流量月份标签和选择器可正确显示各种受支持的语言。
- 现在，CSV导出操作会使用每个辅助功能问题的正确页面URL。
- 不再错误地阻止符合条件的Edge Delivery Services站点部署替代文本。

## 2026年8月20至27日

### 新增功能

- **警报视图** — 查看自动检测到的站点运行状况事件的90天时间线，将更改与部署和内容更新相关联，并在一个位置检查受影响的页面和性能量度。
- **报告和WINS** — 使用“报告”部分查看优化历史记录、性能趋势以及前后WINS，以帮助您传达优化工作的影响。
- **新增功能和帮助中心** — 发现最近发布的功能，打开产品文档，并直接从应用程序内帮助中心访问发行说明。
- **Google Ads连接（抢先体验）** — 连接Google Ads帐户，将付费流量性能数据引入Sites Optimizer机会和推荐。

### 增强功能

- **机会列表控件** — 按URL、星级状态、优先级或回访间隔对机会进行筛选和排序，在URL中保存视图以便共享，以及将建议数据导出到CSV。
- **建议工作流控件** — 在部署之前编辑AI生成的建议，忽略单个建议，跳过完整的机会，并在跳过的机会再次相关时恢复这些机会。
- **部署历史记录** — 按日期查看部署历史记录，将自动部署与标记为手动部署的更改区分开来，并遵循拉取请求链接获取基于代码的修复。
- **Brand与Slack集成** — 选择一个Adobe GenStudio品牌以生成品牌内内容，并与配置的Slack渠道共享相关优化更新。

## 2026年8月6-19日

### 新增功能

- **在AEM Sites页面编辑器中Preflight** — 如果您的创作环境运行AEM 2026.7.0或更高版本，则可直接从“页面编辑器”工具栏中打开Preflight以分析当前页面，而无需离开创作工作流。
- **预检导出选项** — 将预检结果导出为CSV或PDF，其中选项包括运行已传递的元数据和审核，从而更容易共享调查结果并跟踪准备情况。

### 增强功能

- **印前检查会话详细信息** — 继续以前的审核会话时，印前检查会显示运行时间，并通过显示可读文本或CSS选择器使受影响的元素更容易识别。

## 2026年7月1日–19日

### 新增功能

- **权限管理（提前访问）** — 具有“管理用户”功能的用户现在可以通过新的“权限”选项卡控制站点访问 — 按姓名或电子邮件搜索人员以及授予或撤消特定功能。 不允许用户执行的操作显示为已禁用，并带有工具提示来说明如何请求访问权限。
- **部署状态徽章** — 标记为手动部署的修复现在在“已部署”视图中显示一个独特的“标记为已部署”徽章，以便轻松区分手动更新和自动部署。

### 增强功能

- **适用于GitHub的自动修复(Cloud Manager)** — 针对Core Web Vitals、安全和表单辅助功能等业务机会的代码修补自动修复现在可以在托管在GitHub上的Cloud Manager自带Git存储库中提出拉取请求，从而匹配对GitLab、Bitbucket和Azure DevOps的现有支持。 新的“设置”切换开关允许您控制网站的一次性设置确认。
- **通过分支自动修复(Cloud Manager Standard)** — 现在，为您的网站启用Cloud Manager标准存储库后，即可使用通过分支自动修复的功能。
- **已部署视图：执行者** — 现在，已部署视图通过新的“执行者”和“上次更新状态”列，显示将每个修复标记为已部署的人员及其上次更新状态的时间。
- **Google Ads断开连接反馈** — 现在，在“设置”中断开Google Ads帐户将显示“正在断开连接……”状态，如果断开连接失败，则会显示一条可忽略的错误消息，以便您可以重试。

### 错误修复

- 当修补程序跨多个页面时，修复ARIA标签机会现在在详细信息对话框中显示正确的页面URL。
- 现在，“跳过”对话框的信息消息已正确显示，包含正确对齐的韩文、简体中文和繁体中文文本。
- 替换文本和无效或缺少元数据的相关页面对话框现在可以可靠地加载，并且无效或缺少元数据部署的视图和元标记修复现在可以正确使用最新的建议格式。

## 2026年5月11日至22日

### 新增功能

- **网站警报报表（提前访问）** — 新的90天网站警报报表使用颜色编码的每日块突出显示提升的警报时段，提供网站运行状况的季度视图，以便您快速识别和调查一段时间内的趋势。
- **操作遥测载入** — 尚未连接操作遥测数据的站点现在会在主页上接收一个永久性横幅和一个引导式载入对话框以完成设置，从而确保您完全了解真实用户性能。
- **替换文本：多站点管理器感知** — 在为使用AEM多站点管理器或语言副本的站点生成替换文本修复时，Sites Optimizer现在会先检查修复是否可以安全地应用于每个语言变体，然后再提供建议。

### 增强功能

- **替代文本准确性** — 替代文本建议现在从最新的审核信号中提取，并且重新检测到的问题会出现在当前问题和已部署的选项卡中，以便显示全貌。

### 错误修复

- “部署”按钮状态现在可正确反映是否可以实际部署修补程序。
- 深色主题现在可以在页面刷新时正确应用。
- 报表显示用户区域设置中的日期。
- 现在可以单独配置语言和数字/日期格式的区域首选项。
- 屏幕阅读器现在可以访问损坏的图像替换文本。

## 2026年4月21日至5月10日

### 新增功能

- **没有站点已载入状态** — 尚未添加站点的客户现在会在主页看到一个清晰的、可操作的提示，以便快速入门。
- **帮助中心中的文档** — 现在可以直接从应用程序内帮助中心访问Experience League上的AEM Sites Optimizer文档，而无需离开产品。

### 错误修复

- 现在，没有活动建议的网站可正确显示“需要操作”对话框。
- 跳过的建议现在会按预期显示在“已忽略”选项卡中。
- 付费流量选取器下拉列表不再截断已翻译文本。
- Sitemap页面选取器的大小现在已正确设置。

## 2026年3月13日至4月20日

### 新增功能

- **试用入门** — 新的试用用户现在将体验引导式设置流程：输入域，等待分析，然后探索您的第一个机会 — 无需配置即可开始。
- **试用机会页面** — 试用用户可以搜索、排序和筛选机会，其中三个建议已解锁，其余建议显示在带有升级提示的锁定预览中。
- **每月优化进度** — 主页上的进度条可跟踪您本月执行的优化操作数，帮助您始终掌握网站运行状况目标。
- **审核目标URL（提前访问）** — 在“设置”下，您现在最多可以指定100个自定义URL，以确保审核中始终包含这些页面。
- **交付类型配置** — 现在，通过设置可以指定网站的交付类型（Edge Delivery Services、AEM Cloud Service或AEM Managed Services）并连接内容提供商。
- **Core Web Vitals重新设计** — 已重新设计Core Web Vitals机会，它具有Jira链接、CSV下载和对批处理操作的多选支持。
- **已断开的反链接统一表** — 现在，来自所有源的已断开的反链接将显示在单个统一表中，该表能够直接导出CDN重定向规则。
- **No CTA Above the Fold： Deploy to Author** — 对No CTA Above the Fold opportunity的修复现在可以直接部署到AEM Author。
- **Forms Autofix Deploy** — 现在可将Forms机会修复直接部署到AEM Author。
- **AEM多站点管理器支持** — 影响站点的多个语言副本的机会现在会使用“Fixed at”列指示在哪个根站点应用了修复。
- **跳过失败的修复** — 您现在可以跳过部署失败的单个修复，保持工作流未受阻止。
- **在AEM编辑器中打开** — Opportunity建议现在包括一个直接链接，用于在AEM的可视化编辑器中打开受影响的页面以进行快速内联编辑。

## 2026年2月28日至3月13日

### 新增功能

- **广告意图不匹配机会** — 一种新的机会类型可识别未转化的付费流量登陆页面、显示跳出率、每次点击成本以及流量量度，以帮助您优先考虑登陆页面改进。
- **无折叠**&#x200B;上的CTA — 此机会现在是一个专用的顶级类型，具有自己的详细信息页面和筛选条件，从而更易于跟踪转化改进并为其优先排序。
- **Sitemap URL建议** — Sitemap机会现在为返回404错误的页面建议替换URL，以便更轻松地更正损坏的Sitemap条目。
- **重新设计了中断的回链接** — 重新设计了中断的回链接详细信息页面，以提高清晰度和可用性。

### 增强功能

- **热门有机搜索页面V2** — 有机流量数据现在源自30天的Ahrefs数据集，可提供更全面且更可操作的搜索性能见解。
- **安全漏洞：依赖关系树** — 安全漏洞详细信息现在包含依赖关系树可视化图表，以便您了解漏洞对项目的完整影响。

## 2026年2月14-27日

### 新增功能

- **热门有机搜索页面** — 网站运行状况监视器现在包含一个专用选项卡，该选项卡显示您网站的最热门有机流量页面，让您能够了解哪些内容驱动了最多的搜索流量。
- **替换文本自动修复V2** — 在部署替换文本修复程序之前，您可以运行预检“检查修复性”评估，以验证修复程序是否可成功应用于您的内容。
- **替代文本的已部署视图** — 替代文本修复现在显示在“已部署”选项卡中，该选项卡为您提供了有关辅助功能改进的完整历史记录以及当前未解决的问题。
- **外部组织部署入口** — 在将修复部署到外部管理站点时，现在需要明确的确认步骤以防止意外更改。

### 增强功能

- **Meta Tags URL劐免** — 现在可以通过配置从Meta Tags验证中排除特定URL，从而减少有意使用简短或非标准标题的误报。
- **高级URL筛选** — 在按URL筛选时，机会列表现在支持子路由前缀匹配，这样更容易专注于网站的特定部分。
- **改进的趋势图** — 流量趋势图现在可正确处理年同比数据，从而消除年边界处的误导性下降。

## 2026年2月6至13日

### 新增功能

- **维护模式** — Sites Optimizer现在可以正常处理计划的维护时段，在停机期间显示明确的状态消息而不是不完整或误导性的数据。
- **已部署断开的反链接视图** — 现在在“已部署”选项卡中跟踪已修复的反链接，并按日期分组，以便您一眼就能看到修正历史记录。
- **在折页机会上方没有CTA** — 新的机会类型将显示折页上方没有显示清晰call-to-action的页面，帮助您识别和改进转化潜力低的页面。
- **用于辅助功能和颜色对比度的Jira集成（提前访问）** —Forms和颜色对比度辅助功能机会现在可以直接链接到Jira票证，以便在现有工作流程中简化问题跟踪。

### 增强功能

- **Meta Tags &amp; Security的已部署视图** — Meta Tags &amp; Security Opportunity现在包含按日期分组的已部署选项卡，与其他机会类型一致。
- **替换文本部署跟踪** — “标记为已部署”现在可用于替换文本修复，并且在重新分析运行时保留手动编辑的替换文本。

## 2026年1月26日至2月6日

### 新增功能

- **Canonical和Hreflang的已部署视图** — 对Canonical和Hreflang机会的更改现在按部署日期分组到“已部署”选项卡中，以便为您提供已修复内容和修复时间的明确历史记录。
- **CSV导出** — 您现在可以将“有机低限度CTR”和“Forms”业务机会的业务机会数据导出到CSV，以便离线分析和报告。
- **最喜爱的商机** — 从标题中开始添加任何商机，以将其添加到您的收藏夹，从而更快地导航回您正在积极处理的商机。
- **重定向链的“已部署”视图** — 现在可以直接从详细信息页面将重定向链修复标记为已部署。

### 增强功能

- **改进的Cookie横幅成本估算** — Cookie横幅机会的成本计算已得到优化，以提高准确性。

## 2026年1月16-23日

### 新增功能

- **站点运行状况监视器（一般可用性）** — 站点运行状况监视器现在可供所有客户使用，以连续查看您站点的性能运行状况。 新站点在载入时自动设置。
- **子路径网站支持** — 网站运行状况监视器现在完全支持范围为特定URL子路径的网站。

### 增强功能

- **可操作的数据充足性通知** — 页面查看次数少于1,000次的付费流量机会现在会显示数据充足性通知，帮助您将优化工作重点放在流量数据具有统计意义的地方。
- **灵活的Meta标题验证** — 降低了对元标题的最低字符要求，让您在制作简洁的页面标题时更加灵活。
- **本地化的新增功能对话框** — 应用程序内功能公告对话框现在以您的首选语言显示。
- **已发布的徽章** — 已部署的High Organic Low CTR机会中的变体现在显示“已发布”徽章，从而更容易区分活动更改和待处理更改。
- **可访问性中的拉取请求链接** — 可访问性机会的“已部署”选项卡现在会显示每个修复程序的关联拉取请求URL，从而更易于将更改跟踪回源代码管理历史记录。
